THE FRAME STATION — CLOUDFLARE PAGES WEBSITE

UPLOAD:
1. Unzip this file.
2. In Cloudflare Pages, upload the CONTENTS of this folder (index.html must be at the root).
3. No build command is required. This is a static HTML/CSS/JS site.

IMPORTANT:
- The website already includes the finalized Frame Station visual direction and uploaded product photos.
- The WhatsApp buttons currently use WhatsApp's generic share/open flow.
- To send customers directly to your business number, open script.js and set:
  const WHATSAPP_NUMBER = "9715XXXXXXXX";
  Use the full international number without + or spaces.

FILES:
index.html  — website structure/content
styles.css — full responsive design
script.js  — menu, custom-photo preview, filters, WhatsApp actions
assets/    — logo, hero, room inspiration, product images

The website is responsive for mobile and laptop.
